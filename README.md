# RWA.Z4.1 — JavaScript Fundamentals Exercises

A set of 6 small standalone JavaScript exercises from a Web Application Development course,
covering core language fundamentals — variables, loops, arrays, and objects.

## Exercises

| File | Description |
|---|---|
| `z1.html` | Declares variables of different types (number, string, multi-line string, boolean) and prints them |
| `z2.html` | Loops through odd numbers from 1 to 99 and prints each number with its square |
| `z3.html` | Finds and lists all prime numbers up to 1000 |
| `z4.html` | Array operations: sorting ascending/descending, `pop`/`push`, and merging with `concat` |
| `z5.html` | Iterates over an array of person objects, printing each property with a nested `for...in` loop |
| `z6.html` | Adds a method (function property) to an object and calls it |

## Concepts covered

- Variables and data types
- `for`/`while` loops and nested loops
- Array methods (`sort`, `push`, `pop`, `concat`, spread operator)
- Objects, object properties, and `for...in` iteration
- Adding functions as object properties (methods)

## Tech stack

- **HTML5**
- **Vanilla JavaScript** (no frameworks or libraries)

## Running

Each file is self-contained — just open the `.html` file directly in a browser. No build step
or server required.
